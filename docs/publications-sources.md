## Display and sorting rules

Categories are editorial groupings based on the papers' subject matter. Entries within each category sort first by the user's authorship (first-listed author, then another co-first author, then other author), then by date. RESETTLE has equal contributions but Yuxin is first listed, so its explicit `authorship` is `first`. The original author order is preserved for every paper. `#` in this site's BibTeX denotes equal contribution; `*` denotes corresponding author, per PRISM's parser. These are display metadata, not changes to the underlying papers' author order.

The selected papers are RESETTLE, VP-VLA, and EditInfinity. The publication months store initial arXiv release months rather than conference event months. Conference labels reflect the verified accepted/published venue, without inventing proceedings volume, pages, or DOI data where unavailable.
